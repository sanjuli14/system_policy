📖 MANUAL DE JUEGO
OBJETIVO

Resuelve el caso antes de que el tiempo se agote (15 minutos). Encuentra al asesino usando comandos y descubriendo evidencias.

COMANDOS
/analizar [cosa] Analiza una pista o evidencia
/interrogar [nombre] Entrevista a un sospechoso
/acusar [nombre] Acusa al asesino (requiere pruebas)
[pregunta] Pregunta sobre el caso
PELIGROS
  • Si preguntas directamente quién es el asesino: +15% corrupcion, -30 segundos
  • Si el tiempo llega a 0: Game Over
  • Nivel de corrupcion al 100%: Pierdes
COMO GANAR
  1. 1. Explora la escena del crimen
  2. 2. Analiza las pistas encontradas
  3. 3. Interroga a los sospechosos
  4. 4. Descubre contradicciones
  5. 5. Acusa al culpable con las pruebas correctas
EJEMPLOS
/analizar llave /interrogar Maria /acusar Juan
